Política de privacidad

Esta política describe la versión personal de 2DO CEREBRO, identificada en Google como SEGUNDO CEREBRO LOCAL, y esta web informativa. El proyecto es mantenido por el titular de la cuenta de GitHub pComader para su uso personal.

1. Qué datos puede utilizar

La aplicación solicita acceso a Google Tasks para consultar y administrar listas y tareas, incluidos sus identificadores, títulos, notas, fechas y estados. Solicita acceso a Google Calendar para consultar la lista de calendarios y leer o administrar eventos, incluidos sus títulos, horarios, descripciones y, cuando estén presentes y sean accesibles, ubicaciones y participantes.

La autorización también permite obtener credenciales de acceso y renovación. La aplicación no solicita la contraseña de Google. Los permisos efectivos se limitan a los concedidos por el titular y a sus derechos sobre cada recurso.

2. Para qué se utilizan

Los datos se utilizan para realizar las operaciones que solicite el titular y, cuando se implementen y habiliten, las automatizaciones que configure expresamente. Actualmente se ha comprobado la lectura de listas de tareas y calendarios. La conexión con asistentes y la ejecución automática aún no están habilitadas.

Este proyecto no utiliza los datos de Google para publicidad, venta de información ni entrenamiento de modelos propios.

3. Dónde se guardan

Los datos de tareas y eventos permanecen en Google. La aplicación local los procesa en memoria al realizar las consultas. La comprobación actual muestra únicamente el número de listas y calendarios en la ventana del programa y no guarda copias de sus contenidos.

El archivo de configuración del cliente OAuth se guarda en el ordenador del titular. Los tokens se guardan localmente cifrados mediante la protección de datos de Windows, vinculados al usuario de Windows que ejecutó la autorización. No se incluyen en esta web ni en su repositorio público.

Ese cifrado no protege frente a todos los riesgos: un programa que se ejecute con los permisos del mismo usuario de Windows puede tener acceso a las credenciales. El titular debe proteger su equipo, sus cuentas y sus copias de seguridad.

4. Proveedores y asistentes

La aplicación se comunica con Google para autorizar el acceso y realizar las operaciones solicitadas. Esta web se aloja en GitHub Pages y no recibe tareas, eventos ni credenciales de Google.

La versión actual no envía datos de Google a proveedores de inteligencia artificial. Si se incorpora ChatGPT, Claude u otro servicio externo, se deberá revisar esta política y configurar expresamente qué información podrá recibir ese proveedor antes de habilitar la integración. El procesamiento con un modelo realmente local mediante Ollama deberá configurarse sin recurrir a modelos o servicios de nube.

5. Conservación, revocación y eliminación

La credencial local de renovación se conserva hasta que el titular la elimine o deje de ser válida. Para interrumpir el acceso, el titular puede revocar SEGUNDO CEREBRO LOCAL desde las conexiones de su cuenta de Google y eliminar el archivo local token.dpapi. Si vuelve a ejecutar la autorización, se podrá generar una credencial nueva.

Eliminar los archivos del programa o revocar el acceso no elimina las tareas ni los eventos de Google. Estos se administran desde Google Tasks y Google Calendar, o mediante operaciones expresamente solicitadas cuando estén disponibles.

6. Esta web pública

Estas páginas no incorporan formularios, analítica, publicidad, cookies propias ni scripts. GitHub, como proveedor de alojamiento, puede registrar datos técnicos de las visitas, incluida la dirección IP, según su política de privacidad.

Los enlaces externos conducen a servicios con sus propias políticas. No publiques datos de tareas, calendarios, contraseñas ni credenciales en el repositorio o en comunicaciones públicas.

7. Contacto y cambios

Para consultas relacionadas con el acceso a Google, utiliza el correo de asistencia mostrado en la pantalla de consentimiento de SEGUNDO CEREBRO LOCAL. El perfil público del mantenedor es pComader en GitHub.

Esta política se actualizará si cambian los datos tratados, su almacenamiento o los proveedores utilizados. La fecha de actualización figura al principio de la página.
